# FAMS Button & Navigation Theme (Storm Blue)

- Buttons use the shared Storm Blue (#34506D) glass style: rounded gradient body, specular highlight and light edge.
- Sidebar navigation items are frosted white glass on the dark Storm Blue sidebar; the selected item is a bright glass pill with dark text.
- Secondary buttons are translucent white with Storm Blue text; Danger buttons stay red for clear destructive actions.
- Notice deletion keeps the shared danger-button style. Existing navigation and action listeners are unchanged.
